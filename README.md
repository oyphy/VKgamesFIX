## Как запустить

1. Скачай архив по ссылке выше.
2. **Полностью распакуй архив** в любую папку.
3. Запусти **`run.bat`**.
4. Подожди пока поставится Python и нужные библиотеки.
5. Когда откроется VK Play Machine — запускай игру.

> **Важно:** запускай обычным способом, не от имени админа.  
> Окно фикса не закрывай пока играешь.

Если Python сам не поставился:

1. Скачай его с [официального сайта](https://www.python.org/downloads/).
2. При установке обязательно поставь галочку **`Add Python to PATH`**.
3. Снова запусти **`run.bat`**.

## Че делает фикс

- чистит сломанный кэш Play Machine;
- подменяет старый User-Agent браузера;
- убирает блокировку `X-Frame-Options`;
- обходит кривой VK iframe;
- получает прямую ссылку игры от самого VK;
- запускает встроенный в Play Machine Flash;
- сам перезапускается без прав администратора;
- если порт занят старым фиксом — сам ищет свободный.

**Пароли и токены никуда не отправляются.**  
Все работает локально на твоём компе через `127.0.0.1`.

## Если не работает

1. Полностью закрой **VK Play Machine**.
2. Закрой все старые окна фикса.
3. Распакуй свежую версию в новую папку.
4. Запусти **`run.bat`** ещё раз.
5. Не закрывай окно с логами — там будет написана ошибка.

Если старый фикс остался висеть в фоне, новая версия сама попробует его закрыть.  
Закрыл окно фикса — прокси и VK Play Machine тоже выключатся.
