# VK Play Machine Fix

фикс для белого экрана в VK Play Machine. делал в основном для вормикса, но с другими старыми играми тоже может помочь

## как запустить

1. нажми сверху `Code` потом `Download ZIP`
2. распакуй архив куда угодно
3. запусти `run.bat`
4. открой нужную игру
5. черное окно не закрывай пока играешь

в первый запуск батник сам поставит Python и пару библиотек, интернет нужен

если Python сам не поставился, скачай его с https://www.python.org/downloads/  
при установке поставь галочку `Add Python to PATH`

запускай обычным способом, **не от имени админа**, а то могут сломаться куки

## че он делает

в машине стоит старый хром и вк теперь отдает туда кривую страницу вместо игры. фикс подменяет браузер, убирает блокировку iframe и открывает прямую ссылку игры которую отдает сам вк

пароли и токены никуда не отправляются, все работает локально на компе через `127.0.0.1`

## если не работает

- полностью закрой VK Play Machine
- закрой старое окно фикса
- снова запусти `run.bat`
- если порт `8877` занят, значит где то уже висит старый фикс

пока батник открыт игра работает, закроешь его и обход остановится
